# Adhara

React app with dotnet api and postgres database controller by liquibase.

## Required Software

IDE like Visual Studio Code
Docker
Dotnet sdk
Node
Make

## Run

checkout Makefile for availabel commands. To run the application in a docker container run

```make start```

SWagger UI URL: http://localhost:8080/index.html

Open ApI URL: http://localhost:8080/openapi/v1.json

Pgadmin URL: http://localhost:5050/browser/

Checkout docker-compose file for credentails.
